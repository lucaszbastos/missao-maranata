# Modelos originais

Os arquivos explorer.glb e mentor.glb foram criados para este projeto pelo script scripts/create-characters.mjs, usando geometria original. Não contêm assets baixados nem reproduzem personagens oficiais de franquias. Podem ser usados, alterados e distribuídos como parte deste portfólio.

Ambos contêm um SkinnedMesh, oito ossos e os clipes idle, walking e running. Os materiais não dependem de texturas externas.
